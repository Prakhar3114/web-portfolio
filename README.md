## ✨ About This Portfolio

A **premium, interactive, recruiter-focused portfolio website** built from the ground up with modern web technologies. Designed to showcase full-stack AI/ML engineering capabilities through immersive UI/UX and interactive project presentations.

---

## 🎨 Features

| Feature | Description |
|---|---|
| 🌗 **Dark / Light Mode** | Smooth system-aware theme toggle |
| ⌨️ **Typewriter Animation** | Dynamic role cycling in the Hero section |
| 🖼️ **Floating Profile Image** | Continuous physics-based floating animation |
| 🃏 **3D Tilt Cards** | Mouse-tracking perspective tilt on Project & Certification cards |
| 🖱️ **Mouse-Tracking Background** | Ambient gradient blobs that follow the cursor |
| 📊 **Scroll Progress Bar** | Fixed gradient indicator at the top of the viewport |
| 🔍 **Project Modal Popups** | Clickable cards that expand into detailed full-screen views |
| ✅ **Certification Verification** | Direct links to official IBM credential URLs |
| 🛠️ **Logo-Based Skills Grid** | High-res SVG brand logos with hover tooltips |
| 📱 **Fully Responsive** | Optimised for mobile, tablet, and desktop |
| ⚡ **Filter Tabs (Experience)** | Animate — filter timeline by Education or Experience |

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| **Framework** | React.js + Vite |
| **Styling** | Tailwind CSS + Custom Glassmorphism Utilities |
| **Animations** | Framer Motion |
| **Icons** | Lucide React |
| **Hosting** | Netlify (CDN, HTTPS, Free) |

## ⚙️ Run Locally

```bash
# Clone the repository
git clone https://github.com/Prakhar3114/web-portfolio.git

# Navigate into the folder
cd web-portfolio

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

---

## 📦 Build for Production

```bash
npm run build
# Output will be in the /dist folder
```
